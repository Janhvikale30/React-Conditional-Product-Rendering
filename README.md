# React Conditional Product Rendering

A React.js project demonstrating **Conditional Rendering** through category-based product filtering.

## 📌 About the Project

This project demonstrates how Conditional Rendering can be used to display different products based on the user's selection.

The project contains products divided into different categories such as:

- Electronics
- Fashion
- Lifestyle

Users can select different options to dynamically display the required products.

## ✨ Features

- **Products** – Displays all available products.
- **Electronics** – Displays only electronic products.
- **Fashion** – Displays only fashion products.
- **Lifestyle** – Displays only lifestyle products.
- **Laptop** – Displays laptop-related products.
- Dynamic product display based on user selection.

## 🔄 How It Works

The project contains a product array with products from different categories such as Electronics, Fashion, and Lifestyle.

The `map()` method is used to iterate over the product data and display products dynamically.

When the user selects a category or product:

- **Products** → Displays all products
- **Electronics** → Displays electronics products
- **Fashion** → Displays fashion products
- **Lifestyle** → Displays lifestyle products
- **Laptop** → Displays laptop products

Conditional rendering and filtering are used to display the selected products dynamically.
